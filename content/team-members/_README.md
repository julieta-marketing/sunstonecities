# Team Members

Add or edit one `.md` file per person. Files that start with `_` are ignored.

Required fields:

- `name`: Person's name.
- `title`: Role or title.
- `headshot`: Image path from the `public` folder, such as `/team-headshots/Name.jpg`.
- `introductionSummary`: Short copy used on the homepage card back.
- `linkedin`: LinkedIn URL.
- `email`: Email address.
- `cardOrder`: Display order. Lower numbers appear first.

Write the full biography below the frontmatter. You can use the `## Full Introduction`
heading from `_template.md`, or write the biography directly after the frontmatter.

Images should be uploaded to the `public/team-headshots/` folder so the path can be
referenced as `/team-headshots/file-name.jpg`.
